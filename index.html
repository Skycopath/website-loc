No-website business finder

Finds businesses on Google Maps with no listed website. You look up the coordinates manually for email/contact info.
Uses the official Google Places API (New) — not a scraper, so it won't get IP-banned. You need your own API key from the Google Cloud Console with "Places API (New)" enabled and billing set up. Google gives $200/month free credit; a Text Search costs $0.032/call, so this is essentially free at normal volumes. The API only returns coordinates, name, and phone — email is never public, which is why the manual coordinate lookup step stays on you.
